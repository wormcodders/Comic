# Comics Collection App - Design Template

## Color Palette
- **Primary Background**: #1a1a1a (Dark)
- **Card Background**: #2a2a2a (Slightly lighter)
- **Accent/Primary**: #8b5cf6 (Purple)
- **Secondary**: #ef4444 (Red)
- **Text**: #ffffff (White), #a0a0a0 (Gray)
- **Bottom Nav**: #0a0a0a (Black)

## Layout Structure

### Home Page
- **Header**: Category filters (All, Fantasy, Superheroes, Supernatural)
- **Main Content**: 
  - Featured Comics carousel
  - Trending Comics grid
  - Top Authors section
- **Bottom Navigation**: Home, Store, Community, Library, Profile icons

### Category Page
- **Header**: Hamburger menu, date, user icons
- **Content**:
  - "Continue reading" section
  - Category tabs (Trending, New arrival, Downloaded)
  - Comic character merchandise section
- **Bottom Navigation**: Same as home

## Component Guidelines

### Comic Card
- Square/circular cover image
- Title below image
- Rating stars
- Genre tags
- Hover effects with scale/overlay

### Bottom Navigation
- Fixed position at bottom
- Icon-only navigation
- Active state highlight
- Mobile-first design (5 items max)

### Typography
- Headers: Bold, large
- Body text: Medium weight
- Tags/labels: Small, uppercase
- Consistent spacing and hierarchy

## Responsive Breakpoints
- **Mobile**: 320px - 768px (Primary target)
- **Tablet**: 768px - 1024px
- **Desktop**: 1024px+

## Interactive Elements
- Smooth transitions on hover
- Loading states for comic covers
- Swipeable carousels
- Pull-to-refresh functionality
