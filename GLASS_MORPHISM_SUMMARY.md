## 🎨 Customization

### Adjust Glass Intensity
```css
:root {
    --glass-bg: rgba(255, 255, 255, 0.05);  /* More transparent */
    --glass-bg: rgba(255, 255, 255, 0.2);   /* More opaque */
}
```

### Custom Colors
```css
.glass-primary {
    background: rgba(99, 102, 241, 0.15);
    border-color: rgba(99, 102, 241, 0.3);
}
```
